How the dataset-age warning works

The daily source has no assumed publication cutoff. We conservatively expect the last financial-market business day before the local calendar date and warn only at a lag of two or more business days. Weekends and verified holidays do not increase the lag. This is a local warning policy, not an official publication guarantee.

Advanced · official fields and provenance

PU means unit price per bond. Official buy quote (PU Compra): purchase, D+1. Official sell quote (PU Venda): morning early redemption, D+1 before 2021-09-13 and D0 on/after that date. Official base PU (PU Base): mark-to-market valuation, D0. These fields are distinct and never substituted.

Early-redemption scenarios require per-record validation. Historical calendar discrepancies can make a scenario unavailable even when the raw quote exists. Morning-quote scenarios do not model after-13:00 requests or suspended trading.

Local data and offline demo

Import official Prefixado quotes with tesouro-lab sync, then reload. If the server uses --data-dir PATH, pass the same directory to sync. No automatic sync runs in the browser.

For the separate offline scenario demo, stop this server with Ctrl+C and run tesouro-lab demo (from source: go run ./cmd/tesouro-lab demo). The demo uses a temporary database; persistent data stays on disk.
